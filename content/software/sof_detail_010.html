码隐 · CodeHaze 用户手册

软件简介

码隐（CodeHaze） 是一款桌面端代码混淆工具，专为 JavaScript 代码与 After Effects 表达式设计。通过多种混淆技术（字符串编码、控制流平坦化、死代码注入等），将原始代码转化为难以阅读和逆向的形式，有效保护您的逻辑不被轻易窃取。

安装与启动

1. 系统要求

  • 推荐系统：Windows 10 或更高版本（64位）
  • 不支持的系统： macOS、iOS、Android、Linux 及 Windows 32位系统

2. 安装步骤

  • 找到压缩包，解压后双击运行 Setup.exe 。
  • 如出现 “Windows 已保护您的电脑” 或杀毒软件警告，请点击 “更多信息” → “仍要运行”。
  • 进入安装向导后，依次点击 “下一步”，可选择默认安装路径，也可选择其他路径。
  • 安装完成后，桌面上将生成一个 启动图标，名称即为“Code Haze”。

激活说明

永久激活

  • 使用期限: 一次激活，永久使用
  • 激活次数: 激活码与硬件绑定，每个激活码支持一台电脑激活使用

激活流程

  1. 首次启动程序，出现激活窗口
  2. 复制界面中的机器码，发给开发者
  3. 完整的粘贴开发者提供的激活码
  4. 确保网络畅通的情况下，点击"立即激活"按钮
  5. 激活成功后自动进入主界面
  6. 下次启动无需连网，完全离线使用

界面布局

  1. 顶部栏

  • 左侧显示软件中文名称“码隐”
  • 右侧显示软件功能描述

  1. 代码编辑区

  • 原始代码文本框：支持粘贴、直接输入
  • 混淆后代码文本框：只读，显示混淆结果
  • 每个框下方显示行数、字符数和大小统计

  1. 工具栏

  • 混淆代码：根据选中的选项对原始代码进行混淆
  • 复制结果：将右侧混淆后的代码复制到剪贴板
  • 清空所有：一键清空两个文本框

  1. 测试执行区

  • 执行混淆代码：在当前应用内运行混淆后的代码（用于验证功能是否正常）
  • 执行原始代码：运行原始代码（便于对比）

  1. 混淆选项区（左侧为基础组件，右侧为高级调节器）

  • 基础混淆组件：勾选需要的混淆技术（共 20 余项）
  • 高级调节器(v2.0版本支持)：调整各项技术的强度阈值、编码方式等

基本使用流程

步骤1：输入代码

在左侧“原始代码”区域输入或粘贴您的 JavaScript / AE 表达式代码。

您也可以点击 “加载示例” 按钮快速填充一段演示代码。

步骤2：选择混淆选项

根据需要勾选基础混淆功能（推荐保持默认选中项）。

如需精细化控制，可展开右侧“高级调节器”调整阈值或编码方式。

小贴士：勾选“自我保护”和“禁用控制台输出”可大幅提升代码被分析的难度，但可能影响正常调试。

步骤3：执行混淆

点击 “混淆代码” 按钮。稍等片刻（根据代码长度和选项复杂度），右侧区域会显示混淆后的代码。

步骤4：测试混淆结果

  • 点击 “执行混淆代码” 可运行混淆后的代码，观察是否与原代码行为一致。
  • 点击 “执行原始代码” 可运行原始代码，用于对比。

步骤5：保存或复制

  • 点击 “复制结果” 将混淆后代码保存到剪贴板，然后粘贴到您的项目文件中。
  • 若需重新开始，点击 “清空所有” 清空两个文本框。

基础混淆组件详解

| 选项名称 | 作用 | 建议 |

| :--------------- | :--------------------------------------------------- | :------------------------------- |

| 压缩代码 | 删除空格、换行，缩短变量名 | 推荐开启，减小体积 |

| 控制流平坦化 | 将代码逻辑拆分成嵌套循环或 switch 结构，打乱执行顺序 | 强度可通过阈值调节，中等强度即可 |

| 死代码注入 | 插入永远不会执行的代码，干扰阅读 | 适合对抗静态分析 |

| 调试保护 | 检测调试器，一旦打开调试工具则进入死循环或变慢 | 强烈推荐，尤其是 Web 端部署 |

| 禁用控制台输出 | 替换 console.log 等方法为空函数 | 适合发布版本 |

| 混淆标识符 | 将变量名、函数名改为无意义的字符 | 必选 |

| 字符串数组编码 | 将字符串存入数组并编码（Base64/RC4） | 推荐 Base64，平衡性能与保护 |

| 自我保护 | 代码运行时会检查自身是否被修改或调试 | 增加安全性，但略微增加开销 |

| 数字转表达式 | 将数字字面量改为运算表达式（如 100 → 50+50） | 增加分析难度 |

| Unicode 转义序列 | 将字符串转为 Unicode 转义形式 | 辅助混淆 |

常见问题（FAQ）

Q1：混淆后的代码体积变大了很多，正常吗？

是的。多数混淆技术（如控制流平坦化、死代码注入）会引入额外代码，体积增大是正常现象。您可以通过关闭某些选项来减小体积。

Q2：混淆后的代码运行报错怎么办？

  • 检查是否启用了“禁用控制台输出”，如果代码依赖 console 输出，请取消该项。
  • 降低“控制流平坦化阈值”或关闭“死代码注入”。
  • 部分 AE 表达式可能不支持太激进的混淆，建议只使用“字符串编码”“压缩代码”等基础选项。

Q3：如何更新软件？

重新下载新版本安装包覆盖安装即可。配置文件会自动保留（如有配置功能）。

Q4：软件会收集我的代码或统计信息吗？

绝对不会。码隐完全离线运行，不联网，不会上传任何数据。您可以通过系统防火墙禁止其联网进一步确认。

| 更新说明 | 见下方 |

v 2.0.0 版本更新高级调节器。位于界面右侧“高级调节器”面板，用于精细控制部分混淆技术的强度。各参数含义如下：

| 参数名称 | 取值范围 | 说明 |

| :------------------- | :---------------------- | :----------------------------------------------------------- |

| 控制流平坦化阈值 | 0 ~ 1（默认 0.75） | 控制流平坦化的应用比例。值越高，平坦化程度越强，代码越难读，但体积和性能开销也越大。建议保持默认或稍低（0.5~0.8）。 |

| 死代码注入阈值 | 0 ~ 1（默认 0.4） | 死代码注入的密度。值越高，注入的无用代码越多。过低则效果不明显，过高会显著膨胀体积。 |

| 字符串编码 | 无 / Base64 / RC4 | 字符串数组的编码方式。Base64 是平衡选择，RC4 加密强度更高但会增加运行时间。无编码则字符串仅被数组存储，不加密。 |

| 字符串数组阈值 | 0 ~ 1（默认 0.75） | 决定多少字符串会被提取到数组中。值越高，被处理的字符串越多，混淆更彻底。 |

| 包装器数量 | 0 ~ 5（默认 1） | 为字符串数组生成多少层包装函数。层数越多，调用字符串的代码越复杂。 |

| 链式调用 | 布尔（默认开启） | 是否使用链式调用方式访问字符串数组中的元素。开启后可增加分析难度。 |

| 参数最大数量 | 0 ~ 10（默认 2） | 包装器函数允许的最大参数个数。数值越大，生成的函数签名越复杂。 |

| 包装器类型 | 变量 / 函数（默认函数） | 选择用变量还是函数来包装字符串数组。函数形式更难以静态分析。 |

使用建议

  • 常规保护：保持所有默认值即可。
  • 极限保护：将阈值调至 1.0，字符串编码选 RC4，包装器数量设为 3~5，链式调用开启。
  • 性能优先：降低控制流平坦化阈值（0.3~0.5），关闭死代码注入，字符串编码选“无”。
